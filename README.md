## Featured Projects

### 01. SauceDemo Manual Testing

Performed black-box functional testing on the SauceDemo web application, covering nine key modules: Login, Inventory, Sorting, Product Details, Cart, Checkout Information, Checkout Overview, Checkout Complete, and Logout. Created test documentation consisting of a Test Plan, 44 unique test case IDs, and 3 documented bug reports. Applied testing techniques such as Equivalence Partitioning and Boundary Value Analysis to evaluate application behavior under different input conditions.

**Tools:** Microsoft Excel, Google Chrome

[View Manual Testing Project](./01-Manual-Testing/)

### 02. DummyJSON API Testing

Conducted functional API testing on the Products module of DummyJSON, covering 11 test cases using five HTTP methods: GET, POST, PUT, PATCH, and DELETE. Implemented JavaScript test scripts in Postman to validate HTTP status codes, JSON response formats, response properties, and selected product data. Recorded 11 passed test cases in the execution summary.

**Tools:** Postman, JavaScript, DummyJSON API

[View API Testing Project](./02-API-Testing/)

### 03. SauceDemo Automation Testing

Developed automated functional tests for the SauceDemo web application using Selenium WebDriver and Java. Implemented the Page Object Model (POM) design pattern and TestNG to organize and execute test scenarios covering Login, Product, Shopping Cart, and Checkout functionalities. The test suite consists of 21 test executions, all of which passed.

**Tools:** Java, Selenium WebDriver, TestNG, Maven, WebDriverManager, Eclipse IDE

[View Automation Testing Project](./03-Automation-Testing/)
